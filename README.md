# Python_OOP_Chat_System
I am doing the AI/ML course alongside my CS degree and this is my basic understanding of Python Fundamentals.

This is my first small Python project where I tried to use classes and objects.
I made a simple chat system where users can join a chat room, send messages and leave the room.
## What I used
- Classes
- Objects
- Methods
- Lists
- If statements
- Basic Python

## How it works
There are two classes in this project:
- User
- ChatRoom

A user can join a chat room and send messages. The messages are saved so they can be viewed later.
